# MECO Simulation — WPILib 2027 development branch

This branch tracks the 2027 WPILib/SystemCore adaptation. The current source is
the shared, WPILib-independent Jolt physics engine only. The 2027 robot/desktop
adapter, pinned vendor dependency set, compiled consumer integration, and
SystemCore validation are not complete. No 2027 vendordep or compatibility
claim is published.

See [the compatibility status](docs/compatibility-2027.md) and the
[physics model guide](docs/jolt-simulation.md). Changes shared with 2026 belong
in both year branches only after they compile and pass the applicable checks.
